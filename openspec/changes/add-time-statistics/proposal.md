# 添加总耗时和平均耗时统计

## 概述

在标注完成统计的标签页面，增加总耗时总计以及平均耗时统计功能。平均耗时等于总耗时除以总题目数。

## 背景和动机

当前的历史统计标签页显示了：
- 总有效完成次数和无效完成次数
- 题目总数
- 返修统计信息
- 各页面完成详情（包含每个页面的耗时）

但是缺少：
- **总耗时总计**：所有完成页面的耗时总和
- **平均耗时统计**：总耗时除以总题目数，帮助用户了解平均每道题的用时

这些统计信息对于用户评估工作效率和制定工作计划非常有价值。

## 目标

1. 在历史统计标签页中添加总耗时统计
2. 在历史统计标签页中添加平均耗时统计
3. 平均耗时 = 总耗时 ÷ 总题目数
4. 保持现有统计信息的完整性
5. 确保数据计算的准确性和实时更新

## 范围

### 包含内容
- 在历史统计标签页的统计区域添加总耗时显示
- 在历史统计标签页的统计区域添加平均耗时显示
- 计算逻辑基于现有的`completionStats.perPage`数据中的`elapsedSeconds`字段
- 格式化显示（如：总耗时: 1250秒，平均耗时: 125秒/题）

### 不包含内容
- 不修改现有的数据收集逻辑
- 不改变其他标签页的显示内容
- 不修改完成详情列表的显示格式

## 成功标准

1. 用户能在历史统计标签页看到总耗时统计
2. 用户能在历史统计标签页看到平均耗时统计
3. 平均耗时计算正确（总耗时 ÷ 总题目数）
4. 当有新的完成记录时，统计数据能实时更新
5. 显示格式清晰易读
6. 不影响现有功能的正常使用

## 风险和约束

### 技术风险
- 除零错误：当总题目数为0时，平均耗时应显示为0或N/A
- 数据一致性：确保计算基于的是有效的完成记录

### 约束条件
- 必须基于现有的数据结构，不增加新的存储需求
- 必须保持与现有UI风格的一致性
- 计算性能不能影响页面响应速度
