# 质检驳回理由查询算法优化修复总结

## 问题描述
在质检驳回理由查询算法中，信息图标的定位策略使用了过于宽泛的选择器 `[class*="info"], [class*="icon"]`，这会导致匹配到无关元素（如"标注要求"），从而造成定位错误。

## 问题分析
1. **根本原因**: 使用了过于宽泛的CSS选择器
   - `[class*="info"]` 会匹配所有包含"info"字符串的类名
   - `[class*="icon"]` 会匹配所有包含"icon"字符串的类名
   - 这些选择器在页面上可能匹配到多个元素，包括非目标元素

2. **影响**:
   - 插件错误地点击"标注要求"元素而非信息图标
   - 无法正确提取质检驳回理由
   - 用户体验受到影响

## 解决方案
我们采用了多层次的精确定位策略：

## 实现细节
1. **移除宽泛选择器**: 移除了 `[class*="info"], [class*="icon"]` 等宽泛选择器
2. **添加SVG内容定位策略**: 实现了基于SVG路径内容的精确定位机制
3. **添加精确选择器**: 使用特定的类名 `.anticon-info-circle` 进行定位
4. **增强XPath表达式**: 在XPath中添加了 `not(contains(text(), "标注"))` 条件，避免匹配到"标注要求"
5. **保持多策略机制**: 继续使用多策略定位机制，确保在一种策略失效时可以使用其他策略
