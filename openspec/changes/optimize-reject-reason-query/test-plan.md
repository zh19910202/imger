# 质检驳回理由查询算法优化测试计划

## 测试目标
验证修复后的元素定位策略能够正确识别信息图标和关闭按钮，避免匹配到无关元素。

## 测试环境
- Appen标注平台返修题页面
- 不同的页面结构和元素布局

## 测试用例

### 1. 信息图标定位测试
**目标**: 验证信息图标定位策略不会匹配到"标注要求"等无关元素

**步骤**:
1. 打开返修题页面
2. 检查页面是否存在"标注要求"元素
3. 执行信息图标定位策略
4. 验证定位到的元素是否为真正的信息图标

**预期结果**:
- 信息图标定位策略应定位到正确的信息图标
- 不应匹配到"标注要求"等无关元素

### 2. SVG内容特征定位测试
**目标**: 验证基于SVG内容特征的定位策略能够精确定位信息图标

**步骤**:
1. 打开返修题页面
2. 执行基于SVG内容特征的定位策略
3. 验证定位到的元素是否为包含指定SVG路径的元素

**预期结果**:
- SVG内容特征定位策略应能准确找到包含指定路径的SVG元素
- 定位结果应与用户提供的SVG信息一致

### 2. 关闭按钮定位测试
**目标**: 验证关闭按钮定位策略能够正确识别关闭按钮

**步骤**:
1. 打开返修题页面
2. 执行关闭按钮定位策略
3. 验证定位到的元素是否为真正的关闭按钮

**预期结果**:
- 关闭按钮定位策略应定位到正确的关闭按钮

### 3. 两步交互策略测试
**目标**: 验证修复后的两步交互策略能够正常工作

**步骤**:
1. 打开返修题页面
2. 执行两步交互策略（点击关闭按钮，然后双击信息图标）
3. 验证是否能正确提取驳回理由

**预期结果**:
- 两步交互策略应能正常执行
- 能够正确提取驳回理由
