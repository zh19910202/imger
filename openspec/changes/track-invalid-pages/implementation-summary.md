# Track Invalid Pages - Implementation Summary

This proposal has been created to track invalid pages in completion statistics. The following files have been created:

1. `proposal.md` - Main proposal document
2. `design.md` - Technical design document
3. `tasks.md` - Implementation tasks
4. `specs/completion-tracking/spec.md` - Specification for completion tracking

The proposal includes:
- Tracking of invalid page completions separately from valid ones
- Display of invalid page count next to "总有效完成次数"
- Total question count across all pages
- Enhanced UI for better visibility into annotation quality
