# 标注记录统计报表和数据看板提案

## 概述

为 Auxis 扩展添加标注记录的统计报表和数据看板功能，根据不同时间周期（日、周、月）生成对应的数据统计和可视化展示。

## 问题陈述

目前扩展可以收集和存储标注数据，但缺少一个统一的统计报表和数据看板来展示：
- 不同时间周期的标注统计数据
- 工作效率和完成质量分析
- 按题目、任务、日期等维度的数据分解
- 历史趋势对比分析

## 目标

1. **统计报表功能**：支持按日、周、月查询标注记录的统计数据
2. **数据看板UI**：在扩展面板中展示直观的数据可视化和统计图表
3. **时间范围支持**：支持多种时间查询方式（当日、本周、当月、自定义范围）
4. **数据导出**：支持将报表数据导出为 CSV/Excel 格式

## 设计原则

- 与现有的 completionStats 存储机制集成
- 基于 GetUserTaskDetails 接口的数据结构设计
- 使用本地存储优先，支持服务端数据同步
- 清晰的 UI 层次和交互流程

## 相关文档

- 接口文档: `docs/api/dailyinfo.md` - GetUserTaskDetails 接口
- 现有数据收集: `src/appen-data-collector.js` - completionStats 和 submissionLogs

## 关键需求

### 数据模型
- 基于 completionStats 的日粒度聚合
- 支持周粒度和月粒度的统计计算
- 保留历史数据用于趋势分析

### 报表类型
1. **每日报表**：当天的标注统计
2. **周报表**：本周汇总数据和日均值
3. **月报表**：本月汇总数据和按周分解

### 看板展示
- 数据统计卡片（总完成数、有效率、平均耗时等）
- 趋势图表（柱状图、折线图）
- 详细列表视图
