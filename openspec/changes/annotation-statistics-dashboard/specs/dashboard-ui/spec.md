# 数据看板 UI 规范

## 概述
数据看板 UI 为用户提供直观的统计数据展示和交互界面，支持多维度的数据查询、可视化和导出。

## ADDED Requirements

### Requirement: Time Range Selector
#### Scenario:
用户在看板顶部可以快速选择不同的时间范围查看对应的报表数据。

**UI 组件**:
```html
<div class="time-range-selector">
  <button class="time-btn active" data-range="day">今天</button>
  <button class="time-btn" data-range="week">本周</button>
  <button class="time-btn" data-range="month">本月</button>
  <button class="time-btn" data-range="range">自定义</button>
</div>
```

**交互行为**:
- 点击按钮立即刷新看板数据
- 选中按钮高亮显示
- 自定义范围展开日期选择器
- 保存用户的最后选择到 localStorage

**功能实现**:
- "今天": 查询当日数据，固定为当前日期
- "本周": 查询本周一至周日的数据 (ISO 8601)
- "本月": 查询当月 1 日至最后一天的数据
- "自定义": 展示日期范围选择器，支持 30-365 天范围

### Requirement: Statistics Cards
#### Scenario:
看板顶部展示 5-6 个统计卡片，快速显示关键指标。

**卡片内容**:
1. **总标注数**: 本期间的总完成数
2. **有效率**: 有效记录数 / 总数 的百分比
3. **无效数**: 无效记录总数
4. **平均耗时**: 平均每条记录的耗时 (秒)
5. **做题总数**: 标注的题目总数量
6. **环比增长**: 与上一周期的对比增长率 (%)

**卡片样式**:
```
┌──────────────────┐
│ 📊 总标注数      │
│ ┌──────────────┐ │
│ │    1,250     │ │ (大字体数值)
│ └──────────────┘ │
│ 相比上周 +12%    │ (增长率，可正可负)
│ (2024-10-28)    │ (日期范围)
└──────────────────┘
```

**数据更新**:
- 卡片数据随时间范围选择实时更新
- 不同的时间范围显示不同的基数（日/周/月的平均值）
- 加载状态显示骨架屏或淡化效果

### Requirement: Trend Chart
#### Scenario:
看板中部展示趋势图表，帮助用户了解完成量和有效率的变化趋势。

**图表类型**:
1. **柱状图**: 日完成数对比 (显示最近 7-30 天)
2. **折线图**: 有效率趋势 (显示最近 7-30 天)
3. **组合图**: 完成数 + 有效率对比

**交互功能**:
- 鼠标悬停显示数据提示 (tooltip)
- 支持放大缩小查看详情
- 支持导出图表为图片
- 图表宽度自适应容器

**数据映射**:
- X 轴: 日期或周号
- Y 轴: 数值 (完成数、百分比)
- 颜色编码: 不同系列用不同颜色

### Requirement: Detailed Data Table
#### Scenario:
看板下方显示详细的数据列表，支持排序和分页。

**表格列**:
| 列名 | 类型 | 说明 |
|------|------|------|
| 日期 | date | YYYY-MM-DD |
| 完成数 | number | 本日总完成数 |
| 有效数 | number | 本日有效数 |
| 无效数 | number | 本日无效数 |
| 有效率 | percent | 有效数 / 完成数 |
| 平均耗时 | number | 秒数，可选显示分:秒格式 |
| 做题数 | number | 本日标注题目总数 |

**表格功能**:
- 按列排序 (完成数、有效率、耗时等)
- 分页显示 (每页 10/20/50 行可选)
- 行悬停高亮
- 可展开行查看按任务的详细统计

**响应式设计**:
- 宽屏: 显示全部列
- 中屏: 隐藏做题数列
- 窄屏: 显示核心列 (日期、完成数、有效率)

### Requirement: Data Export
#### Scenario:
用户可以导出当前查询范围的报表数据为 CSV 格式。

**导出功能**:
- 导出按钮位于看板右上角
- 点击显示导出选项菜单
- 支持导出格式: CSV (Excel 可用)
- 自动生成文件名: `statistics_YYYY-MM-DD_to_YYYY-MM-DD.csv`

**CSV 内容**:
```
日期,完成数,有效数,无效数,有效率,平均耗时(秒),做题数
2024-10-28,45,40,5,88.89%,80,120
2024-10-29,52,46,6,88.46%,75,130
...
总计,314,280,34,89.17%,79.2,3600
```

**导出流程**:
1. 用户点击导出按钮
2. 系统生成 CSV 格式数据
3. 触发浏览器下载
4. 显示导出成功提示

### Requirement: Real-time Data Refresh
#### Scenario:
用户在看板页面时，若有新的标注完成，看板数据应该实时更新。

**更新机制**:
- 监听 completionStats 的变化事件
- 仅在当前时间范围内有新数据时才刷新
- 显示数据更新的视觉反馈 (如数字变化动画)
- 支持手动刷新按钮

**性能优化**:
- 防抖处理，避免频繁更新
- 增量更新，只刷新变化的部分
- 后台更新，不中断用户操作

### Requirement: Empty State & Loading State
#### Scenario:
当没有数据或数据加载中时，提供清晰的用户提示。

**Loading 状态**:
- 显示骨架屏 (Skeleton)
- 显示加载动画
- 按钮禁用，防止重复操作

**Empty 状态**:
- 没有数据时显示空状态页面
- 提示信息: "该时间范围内暂无数据"
- 提示用户可以选择其他时间范围
- 显示建议操作（如导航到其他时间范围）

**Error 状态**:
- 数据加载失败时显示错误提示
- 显示错误信息和重试按钮
- 记录错误日志

## Styling Guidelines

### 颜色方案
- 主色: #2196F3 (蓝色，用于按钮和高亮)
- 成功: #4CAF50 (绿色，用于有效率、增长)
- 警告: #FF9800 (橙色，用于无效、下降)
- 背景: #f5f5f5 (浅灰，卡片和表格背景)
- 边框: #e0e0e0 (灰色边框)
- 文字: #333333 (深灰，正文文字)

### 字体大小
- 标题: 16px, bold
- 卡片数值: 28px, bold
- 卡片标签: 12px, regular
- 表格文字: 13px, regular
- 提示文字: 12px, regular

### 间距
- 外边距: 20px
- 内边距: 15px
- 卡片间距: 10px
- 行高: 1.6

## 响应式设计

### 断点
- 大屏 (>= 800px): 显示全部功能和列
- 中屏 (600-800px): 隐藏部分列，调整卡片布局
- 小屏 (< 600px): 单列布局，隐藏次要列

## 性能要求

- 看板加载时间: < 1 秒
- 时间范围切换: < 500ms
- 数据表分页: < 200ms
- 图表绘制: < 300ms
- 导出操作: < 1 秒
